# Parity with Tauri

Tauri's feature list is cross-platform. crust is macOS 13+ on Apple silicon only, so this page
compares against **Tauri's macOS column** and says plainly what is out of scope by design.

Measured 2026-11-15 against the tree at `v0.1.21`. A row marked *same* means crust ships the
capability; *partial* names the piece that is absent; *via Bun* means the backend half already has it
and no page-facing API is needed; *module only* means the plugin exists but no runtime registers it,
so the app mounts it with `app.use`.

## Out of scope by design

- Windows, Linux, iOS and Android targets.
- Tauri's mobile-only features: barcode scanner, biometric, geolocation, haptics, NFC.
- A Rust plugin ABI. crust plugins are TypeScript objects registered on the `App`.

## Core

| Tauri | crust | Status |
| --- | --- | --- |
| Windows | `window`, 25 commands: create, close, focus, title, list, size, position, always-on-top, fullscreen, minimize, maximize, decorations, opacity, cursor | same |
| Webviews | one `WKWebView` per window | same |
| Menus | `menu.setAppMenu/showContext/reset`, `NSMenu` in `98`+`99` | same |
| Tray | `tray` plugin with menu rows | same |
| Events | `crust.listen` over SSE, `PluginContext.emit` | same |
| Path | `node:path` in the backend | via Bun |
| DPI, image | CSS pixels and `<img>` in the page | via Bun |
| Localhost server | `crust dev`, and the bridge in production | same |

## What this means

Counting the rows above — 29 in all — crust ships **11 outright**, has **8 more available through
Bun** with no extra API, is **partial on 8** (windows, menus, clipboard, OS information, shell, window
state, positioner, logging), and ships **2 as modules the app registers itself** (deep linking,
updater). None is missing.

The *partial* rows are depth, not absence: each names the piece that does not exist, so the gap is
readable. The *module only* rows are one `app.use` away — the plugin, its argument rules and its
failure codes are written and tested; what it lacks is a decision only the app can make: which scheme
it registers, and which endpoint it trusts.
